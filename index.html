Projeto académico Desktop · Gestão comercial

Livraria MMS, Lda.

Sistema de gestão desktop para uma livraria, desenvolvido em Java com interface Swing sobre uma base de dados MySQL com 31 tabelas. O sistema abre num menu principal com login por utilizador (seleção de funcionário + password numérica) e distribui o trabalho por módulos: Gestão de Stock, Controlo de Vendas, Relatórios, Clientes, Caixa e Encomendas.

Contribuí com os módulos de UI do ponto de venda (POSper) — o ecrã de vendas com teclado numérico e categorias de livros (Ação, Aventura, Comédia-romântica, Horror, Novel, Romance, SCI-FI), o ecrã de produtos (TelaProducts) com sub-painéis CRUD, a manutenção de stock com registo de movimentos (entradas/saídas com motivo e armazém), e o fecho de caixa com contagem física de notas e moedas (MT), comparando o valor contado com o esperado.

No módulo de Administração implementei a gestão de funcionários (NIF, data de nascimento, salário, data de admissão, departamento e supervisor), e no módulo de Relatórios os relatórios de stock (todos os produtos, inventário atual), fecho de caixa (entradas, saídas e saldo líquido por período) e vendas por produto (unidades, preço e total faturado).

O projeto incluiu planeamento de arquitetura MVC e um modelo entidade-relacionamento (Chen) desenhado em Mermaid, com relatório académico formal em Word.

Projeto académico Desktop · Gestão

Sistema de Gestão de Farmácia

Aplicação desktop em Java Swing para gerir o dia a dia de uma farmácia: clientes, produtos, fornecedores, armazéns e vendas, tudo acessível a partir de um menu principal com navegação por CardLayout e relógio em tempo real. O acesso é protegido por um ecrã de login.

Cada módulo segue um padrão CRUD consistente (criar, editar, remover, listar em tabela), e os produtos têm controlo de stock mínimo e validade, com um módulo de filtros dedicado para detetar stock baixo e produtos perto de expirar.

O módulo de Vendas funciona como um carrinho de compras: seleciona-se o cliente e o produto, adiciona-se ao carrinho, e o sistema calcula o subtotal com IVA (17%) automaticamente. A venda é confirmada num diálogo de resumo e, ao concluir, gera um recibo com o detalhe de cada item e atualiza o stock.

A persistência é feita por serialização de objetos Java (ObjectOutputStream/ObjectInputStream) para ficheiros .dat, usando uma interface marcadora (Serializable) que permite guardar coleções polimórficas — clientes, produtos, fornecedores, armazéns e vendas — na mesma estrutura genérica.

Projeto pessoal Web · Gestão de stock

Gestão de Stock — Restaurante

Sistema web de gestão de stock, compras e caixa para um restaurante (bar, talho e armazém), com backend em Spring Boot/Spring Security e sessão mantida por cookie HTTP. O ecrã de Resumo dá uma visão geral com produtos cadastrados, movimentos, total de compras e fechos, além do stock distribuído por localização (Armazém, Bar, Talho).

O módulo de Movimentos regista entradas, transferências, vendas, quebras, reservas e ajustes por produto, com localização (origem → destino), funcionário responsável e motivo — por exemplo, vendas apuradas por contagem de geleira no bar. O módulo de Reservas permite separar carne do armazém para eventos ou encomendas nomeadas.

O Fecho/Caixa é feito por funcionário e consultor, repartido por método de pagamento (M-Pesa, e-Mola, POS por banco — BIM, BCI, FNB — e numerário). Os módulos de Carnes e Compras de Comida cobrem o catálogo de produtos vendidos por peso e o registo de compras do restaurante, e a secção de Relatórios gera impressões de armazém de bebida, talho, fecho de caixa e registo de comida, além de indicadores gerais do sistema.
